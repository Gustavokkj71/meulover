# Rayanny Portfolio - Guia Rápido

## 🚀 Como Rodar o Projeto

### Pré-requisitos

- Node.js (v14 ou superior)
- npm ou yarn

### Passos

1. **Abra o terminal na pasta do projeto**

   ```
   cd c:\Users\Gustavo\Documents\AAAIMPORTANTE\PROGRAMACAO\rayray
   ```

2. **Instale as dependências**

   ```
   npm install
   ```

3. **Inicie o servidor**

   ```
   npm start
   ```

4. **Acesse no navegador**
   - Abra: http://localhost:3000

## 📝 O que o Site Contém

✅ **Header Responsivo** - Menu de navegação com tema on/off
✅ **Hero Section** - Apresentação inicial atrativa
✅ **About** - Informações pessoais com estatísticas
✅ **Skills** - Habilidades profissionais com barras de proficiência
✅ **Projects** - Portfólio de projetos com links
✅ **Contact** - Formulário de contato e informações
✅ **Footer** - Links rápidos e informações adicionais

## 🎨 Recursos Especiais

🌊 **Fundo Animado** - Orbs coloridos e formas flutuantes
🌓 **Tema Dinâmico** - Alterne entre modo claro e escuro
📱 **Responsivo** - Perfeito em qualquer dispositivo
⚡ **Animações Suaves** - Transições e efeitos visuais

## 🔧 Personalizar o Conteúdo

### Email

Procure por "rayanny@example.com" e altere para seu email

### Telefone

Procure por "(11) 99999-9999" e adicione seu número

### Redes Sociais

Procure por `href="#"` nos arquivos Contact.js e Footer.js

### Projetos

Edite o array `projects` em Projects.js

## 📦 Build para Produção

```bash
npm run build
```

## 💡 Dicas
