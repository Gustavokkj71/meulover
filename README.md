# 📊 Portfólio de Rayanny

Um site de portfólio moderno, responsivo e interativo para Rayanny, estudante de Contabilidade.

## ✨ Características

- **Responsivo**: Funciona perfeitamente em dispositivos móveis, tablets e desktops
- **Tema Dinâmico**: Alternar entre modo claro e escuro
- **Animações Fluidas**: Fundos animados com gradientes coloridos e formas flutuantes
- **Seções Completas**:
  - Hero com apresentação pessoal
  - Sobre mim com estatísticas
  - Habilidades com barras de proficiência
  - Projetos com detalhes
  - Formulário de contato
  - Footer com links rápidos

## 🛠️ Tecnologias Utilizadas

- React 18.2.0
- CSS3 com animações avançadas
- JavaScript ES6+
- React Icons
- HTML5

## 📦 Instalação

1. Navegue até a pasta do projeto:

```bash
cd rayray
```

2. Instale as dependências:

```bash
npm install
```

3. Inicie o servidor de desenvolvimento:

```bash
npm start
```

4. Abra [http://localhost:3000](http://localhost:3000) no seu navegador

## 🎨 Personalizações

### Alterar cores principais

Procure por `#4f46e5` (roxo principal) e `#ec4899` (rosa) nos arquivos CSS para alterar a paleta de cores.

### Adicionar informações pessoais

- **Header.js**: Logo e navegação
- **Hero.js**: Título, subtítulo e descrição principal
- **About.js**: Informações pessoais e estatísticas
- **Contact.js**: Email, telefone e redes sociais
- **Footer.js**: Links e informações do rodapé

### Adicionar projetos

No arquivo `Projects.js`, adicione novos objetos ao array `projects` com os dados do seu projeto.

## 📱 Responsividade

O site é totalmente responsivo com breakpoints em:

- Desktop: 1024px+
- Tablet: 768px - 1023px
- Mobile: Até 480px

## 🌙 Tema Escuro/Claro

O tema é persistido no localStorage, então a preferência do usuário é mantida entre sessões.

## 🚀 Deploy

Para compilar para produção:

```bash
npm run build
```

Os arquivos compilados estarão na pasta `build/`.
